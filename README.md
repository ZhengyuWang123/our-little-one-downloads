## 第一次走进小窝

1. 下载后把压缩包**全部解压**，保留文件夹内所有文件。
2. 进入 `win-unpacked` 文件夹，双击 `小小同伴.exe`。
3. 填入私发的同步地址和配对码，再写下你的名字。

下载文件保存在 GitHub，主人电脑关机时也可以下载安装，不需要登录 GitHub。她不用安装 Tailscale，也不用登录 Codex。

首次配对及两人共养、聊天同步仍需主人电脑和小小同伴运行。已经配对后，离线期间可以查看缓存，动作会等待恢复连接后同步。

当前为 Windows x64 0.3.0 测试包，由 Linux 交叉打包，尚未在真实 Windows 电脑上验证。下载文件不包含配对码、聊天或存档。
