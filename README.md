## 安装和进入小窝

1. Windows 推荐下载安装版 exe，运行后按提示进入小窝。也可下载本版 `windows.zip`，完整解压后运行 `win-unpacked/小小同伴.exe`。
2. 首次进入时填写主人私下分享的配对信息和你的名字。已配对的用户升级时继续使用原有小窝，不要删除存档目录。
3. 升级前等待发送完成、保存草稿并正常退出旧版；升级后核对设置中的版本。

下载无需登录 GitHub。双方联网后通过独立云服务同步，共养和聊天不要求主人电脑保持运行，也不要求安装 Tailscale。自己的 Codex 登录只用于可选的本机分析和制作功能。
